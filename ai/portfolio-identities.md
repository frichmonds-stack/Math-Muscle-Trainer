# Portfolio Identities

Permanent Sync Keys for Math Muscle Trainer items curated into the AI Project Manager Notion Work Queue. This file records only canonical item name to stable key; status, rationale, and history live in the repository's task/decision owners, Notion, or Git.

Before assigning a key, compare existing Math Muscle Trainer Work Queue rows by meaning. Reuse an equivalent row's key, even if its title changed. If the Work Queue cannot be checked, leave delivery pending for identity reconciliation rather than inventing a key. Add a row here only when an item is about to be delivered.

Keys use three lowercase kebab-case segments: `math-muscle-trainer:<area>:<item>`. Decision items use the `decision` area. Never regenerate a key from a changed title.
