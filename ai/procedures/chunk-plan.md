# Chunk Plan Procedure

Use when the owner says `Chunk Plan`. This is planning only; do not edit repository files.

1. Inspect the relevant route, current code, constraints, and unresolved decisions.
2. Split work into small owner-selectable batches with a clear outcome for each. Keep teacher-authored lesson content separate from renderer or state refactors where practical.
3. For each chunk, state scope, exclusions, likely files, dependencies or owner decisions, acceptance criteria, checks, and whether a lasting decision needs an ADR.
4. Order chunks so a completed one is useful on its own. Label uncertain work as an investigation instead of pretending its implementation is already specified.
5. Recommend the next chunk and stop. Planning does not authorize execution or publication.
