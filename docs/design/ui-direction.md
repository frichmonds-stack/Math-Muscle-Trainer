# Math Muscle Trainer UI Direction

This is the short product-level visual north star. Read `docs/design/visual-design-system.md` first for canonical rules and screen ownership.

## North Star

Math Muscle Trainer should feel like an iPad training app a child can understand and an adult would not feel silly using.

The tone is:

- calm
- tactile
- strong
- readable
- all-ages
- purpose-built for arithmetic practice

Minimalism is a learning strategy here, not just a visual preference. It should reduce extraneous cognitive load and keep attention on the task.

## Experience Direction

- app-like, not webpage-like
- touch-friendly, not cramped
- visually restrained, not empty
- motivating, not arcade-noisy
- strong, not aggressive

## Product Reading Notes

- Home is the startup dashboard.
- Setup is the workout preparation surface.
- Practice and Learn should center the learner task loop.
- Progress should foreground useful evidence, not decorative analytics.
- Options and support surfaces should stay compact.

## Visual Cautions

Avoid:

- nested boxes and containment for their own sake
- corporate dashboard styling
- marketing landing-page composition inside the app shell
- icons added to every button without meaning
- tiny text used to rescue a bad layout
